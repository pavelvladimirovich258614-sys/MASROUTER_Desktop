# MASROUTER Desktop — Руководство пользователя

## 1. Первый запуск

При первом запуске вы попадаете на **Дашборд**. Здесь доступны:

- Кнопка «Новая задача» — открывает **Маршрутизатор**.
- Кнопка «Настроить модели» — открывает **Модели**.
- Кнопка «Открыть справку» — отправляет в **Help** (15 статей на русском).
- Карточки со статистикой: подключённые провайдеры, число запросов, режимы.
- Бенчмарки MasRouter (Таблица 1, последняя строка).
- Список последних 5 сгенерированных промптов.

## 2. Создание задачи

1. Откройте **Маршрутизатор** в боковом меню.
2. Введите описание задачи — **одна атомарная правка**.
3. Выберите **тип** (Правка кода, Баг, Деплой, и т.д.).
4. Укажите **сложность** (Low / Medium / High).
5. Отметьте **флаги риска** — деньги, оплата, скидки, безопасность, БД, деплой, серверная правка.
6. Опционально: выберите **бюджет** (AUTO / ECO / BALANCED / QUALITY).
7. Нажмите **«Рассчитать маршрут»**.

Под формой — кнопки с примерами задач (от «поменять кнопку» до «подготовить деплой»).

## 3. Чтение результата маршрута

После расчёта справа появится карточка с:

- **Risk Score** (1/2/3) — цветной бейдж.
- **Cost Mode** (ECO/BALANCED/QUALITY).
- **λ** (25/15/5) — параметр trade-off из статьи.
- **Топология** (Single, Chain, FullConnected, и т.д.).
- **Число агентов**.
- **Cascade Diagram** — три квадрата Fθt / Fθr / Fθm.
- **Цепочка ролей** — какая роль какую модель использует.
- **Stop Conditions** — при каких условиях остановиться.
- **Server Safety Checklist** — для серверных правок.
- **Final Prompt** — большой блок с кнопками Копировать / Отправить в модель / Open in Codex.

## 4. Подключение моделей

См. [MODELS_SETUP_RU.md](MODELS_SETUP_RU.md). Краткий чеклист:

- **Ollama** — локально, бесплатно, без API-ключа. Скачайте модель, укажите в Моделях, протестируйте.
- **OpenAI / OpenAI-compatible** — нужен API-ключ. Введите его через кнопку «+ Установить».
- **MiniMax / StepFun** — OpenAI-compatible, ключ из кабинета.
- **Custom REST** — для нестандартных API.

## 5. Стоимость

Каждый вызов LLM логируется:

- **Стоимость** → таблица с фильтрами по модели и режиму.
- Наверху — общая сумма, число запросов, sparkline по дням.

## 6. Codex CLI

См. [CODEX_INTEGRATION_RU.md](CODEX_INTEGRATION_RU.md). Краткий чеклист:

1. Установите Codex CLI (`npm i -g @openai/codex` или аналог).
2. Откройте **Codex CLI**.
3. Укажите профиль (CLI путь, шаблон команды).
4. Укажите Project Path и Git Branch.
5. Рассчитайте маршрут.
6. Создайте task.md.
7. Скопируйте команду.

## 7. Безопасность

- **API-ключи** хранятся в `safeStorage` (зашифрованы ОС). В UI — только маска.
- **Shell-команды** по умолчанию ВЫКЛЮЧЕНЫ. Включение → whitelist.
- **Экспорт/импорт** всех данных через JSON.

## 8. Тема

- **Тёмная** (по умолчанию) — чёрно-бирюзово-зелёная.
- **Светлая** — бело-бирюзовая.
- Переключение: Topbar или **Settings → Внешний вид**.
